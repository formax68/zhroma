`priority-representation` ledger entry, which records that exact header as the only
permitted Priority fallback.

Priority header token, and validates its own output before writing.

| Boundary | Description |
|----------|-------------|
| Untrusted capture markup → Priority resolution | Malformed or mixed direct children decide which cell's text is treated as an allowed Priority label. |
| Caller-supplied denylist path → filesystem read | The denylist contains the exact private values being excluded; its location decides whether they can be committed. |
| Sanitizer output → repository bytes | Output that violates the grammar is indistinguishable from tenant content once committed. |
