<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Manifest declarations → admitted scenario semantics | Declared purposes, kinds, and indexes decide what a fixture is taken to prove. |
| Manifest path strings → physical files | Path aliasing decides whether three scenarios rest on three files or one. |
| Admitted bytes → downstream trust | A matching hash proves integrity, not provenance or grammar conformance. |
| Malformed JSON → error model | An uncoded exception is an unhandled admission path. |
