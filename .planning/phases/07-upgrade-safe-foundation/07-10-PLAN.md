2. Stripper. Append a new section after the last existing test. Add `codeOf(source)`: one pass of a single global regular expression with ordered alternation:
   - (a) a single-quoted string and (b) a double-quoted string, each confined to one line and honouring backslash escapes;
   - (c) a template literal (any content, honouring backslash escapes);
   - (d) a block comment;
   - (e) a line comment.

   The replacer works as follows:
   - A quoted string whose inner text is exactly one of the banned names (the network names in step 3, plus `sync`) is returned unchanged. Any other quoted string becomes its two quote characters with nothing between them.
   - A template literal is returned unchanged. It is scanned whole, which fails closed.
   - A block comment becomes whitespace, keeping its newlines.
   - A line comment becomes the empty string.

   Strings are matched before comment openers. This is what stops `'/*'; fetch(u); '*/'` and `'//'; fetch(u)` from hiding code (the debug's naive-stripper finding). In the same new test that proves the stripper:
   - assert exact outputs for a small synthetic source that contains each construct;

4. Sync rule. Add `SYNC_NAME`, the word-bounded `sync` with the `u` flag. In its own new test:

5. Scheme-relative rule. Add `SCHEME_RELATIVE` = ``/[`'"(=,]\s*\/\/[^\s/]/u``. That is: a backtick, quote, opening parenthesis, equals sign or comma; optional whitespace; two slashes; then one character that is neither whitespace nor a slash. In its own new test:

   - the RAW text of every discovered script, page and stylesheet does not match.
