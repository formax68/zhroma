<objective>
Build the opt-in rule-columns mode of the existing fixture sanitiser and the matching manifest validator, so the live session in Plan 03 can admit multi-column, identity-region and dark-mode captures without changing a byte of the v1 corpus.

Purpose: RECON-06 needs sanitised fixtures that keep the rendered shape of the rule columns (avatars, time elements, tag chips, hidden spans, aria-label-only cells) while tokenising every tenant value by kind and by value; RECON-05 needs the agent's own name mapped to one reserved token everywhere it appears. D-10 (locked, rated costly) requires this to be a separate, explicitly selected mode of the same sanitiser with the same sensitive scan and fail-closed rejection, never a change to the default.
Output: `scripts/rule-column-contract.js` (new), a rule-columns branch in `scripts/sanitize-fixture.js`, `validateRecon2Fixtures` in `scripts/fixture-contract.js`, and two new test files. The real `test/fixtures/manifest.json` is not edited in this plan.
