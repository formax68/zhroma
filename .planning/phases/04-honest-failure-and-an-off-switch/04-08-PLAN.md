<objective>
Close **WR-04's worker hop**, **WR-03** and **WR-10**, and build the gate that makes a
"mutant killed" claim checkable rather than asserted.

Purpose: three failures currently launder into something that looks fine.
(1) `setEnabled` awaits `requestApply` with no bound and `requestApply` awaits
`chrome.tabs.sendMessage` with no bound, so one top frame that stops answering leaves the off switch
inoperative **in every tab** until Chrome terminates the worker — with no honest message, in a phase
whose promise is control without uninstalling. (2) Both test doubles model a rejected read as
`callback(undefined)`, so the observed dormancy comes from the falsy path and the `lastError`
branches the source comments call load-bearing have no coverage in either process. (3) The tracer's
fake Chrome asserts `frameId` with `expect` **inside** a call the worker makes within a
`try`/`catch`, so a real contract violation is swallowed by production code and converted into
`unavailable`.

Output: a bounded worker, a read mode that makes `lastError` load-bearing, a double that records
violations instead of throwing them into a `catch`, and `npm run test:mutants` — a re-runnable
out-of-tree gate that requires each registered mutant to fail.

Reference: `04-REVIEW.md` → WR-03, WR-04, WR-10, and `## Required judgment 1` groups B and E.
</objective>

  <action>
    Create `scripts/verify-mutation-kills.js`, an ESM Node script with no dependencies.

    It discovers every `test/mutants/*.mutants.json` file with `readdirSync` and concatenates their
    entries. Each entry is an object with `id`, `file`, `find`, `replace`, `suites` (an array of test
    paths) and `note`, plus an optional `count` defaulting to `1`. `find` and `replace` are literal
    strings, never regexes, so a registered mutant is unambiguous.

    For each entry the script:

    1. Asserts `find` occurs in `file` exactly `count` times. A count mismatch is a **loud failure**,
       not a skip: a stale mutant that no longer matches is a silent no-op, which is the exact class
       of defect this gate exists to catch.
    2. Builds an out-of-tree copy in `mkdtempSync` with `cpSync(root, dir, { recursive: true, filter })`,

    5. Runs `spawnSync(process.execPath, ['node_modules/vitest/vitest.mjs', 'run', '--config', 'vitest.config.js', ...suites], { cwd: dir })`.
