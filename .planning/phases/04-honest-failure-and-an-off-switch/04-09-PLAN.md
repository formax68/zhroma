<objective>
Close **WR-09**: stop the workload harness from failing open, and make the off-state control measure
the shipped off state instead of a different program.

Purpose: the page derives its mode from `params.get('mode') === 'enabled'`, so any other value —
a typo, an omitted parameter — silently means *disabled*, and disabled mode installs no seam and never
loads `content.js`. `verify()` then expects zero markers and zero observers, so a mis-invoked
"enabled" run reports `passed` with 0 callbacks and 0 writes and exits 0. Six such runs are the
timing evidence `04-VALIDATION.md` records as `passed` and `phase-04-live-acceptance.test.js`
consumes. Separately, the seam's `get` always answers `{...defaults}`, so **no run has ever exercised
a stored `false`** — the disabled control measures a page with no extension, which establishes
nothing about the cost of a loaded controller that declines to act.

Output: parameters that throw before any measurement, a third `dormant` mode that installs the seam,
stores `false`, loads the runtime and asserts real dormancy, and a `runtime` field in the report so
the no-runtime baseline is named rather than conflated.

Reference: `04-REVIEW.md` → WR-09.
</objective>
