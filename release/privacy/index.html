Zhroma — Privacy Policy

Effective date: 11 September 2026

Zhroma is a Chrome extension that colours ticket rows in Zendesk agent views according to the priority already shown in the view. It is published by Michalis Efstratiadis (“the publisher”, “we”).

This policy describes everything Zhroma does with data. It is short because Zhroma does very little.

What Zhroma reads

Zhroma runs only on pages matching https://*.zendesk.com/agent/*. On any other page it is never injected and does nothing.

On those pages, Zhroma reads content that Zendesk has already rendered in your browser, in order to decide which rows to colour:

  • the structure of the ticket table — which elements are the table, its head, its body, its rows and its cells;
  • the text of the column headings, to find the column named Priority;
  • the text of the Priority cell in each ticket row, which is matched against the four values Urgent, High, Normal and Low;
  • the language the page declares for itself, so that Zhroma can stay inactive on interfaces it does not read.

This reading is how the extension works, and we state it plainly rather than claiming that Zhroma never accesses anything. The reading happens entirely inside your browser, while the page is open. The values read are used to set a colour on a row and are not copied, saved, logged, exported or sent anywhere. Zhroma does not read ticket subjects, requester names, email addresses, comments, attachments, form data, cookies, authentication tokens, browsing history, or any page outside the Zendesk agent interface.

What Zhroma stores

Zhroma stores exactly one thing: whether tinting is switched on or off. It is a single true/false value, held in your browser's local extension storage under one key. No ticket, customer, view, account or usage information is stored.

That value stays on your device. It is kept until you change the switch, clear your browser's extension data, or uninstall Zhroma, at which point it is gone. There is nothing else to delete, because there is nothing else kept.

What Zhroma sends — nothing

Zhroma makes no network requests of any kind. It has no server, no backend and no API. It contains no analytics, no telemetry, no crash reporting, no advertising and no tracking code of any kind, and it loads no remote code, fonts, styles or images.

As a result, the publisher receives no data from the extension at all. Nothing about you, your tickets, your Zendesk account or your browsing is collected, transmitted, sold, rented, shared with third parties, or used for advertising, profiling or credit decisions. No human has access to your ticket data through Zhroma, because Zhroma never takes it anywhere.

Permissions

Zhroma requests one Chrome permission, storage, and uses it only to remember the on/off switch described above. It declares no host permissions beyond the content-script match https://*.zendesk.com/agent/* that gives it access to the Zendesk agent interface and nowhere else.

Limited Use

Zhroma's use of user data complies with the Chrome Web Store User Data Policy, including the Limited Use requirements. The only data Zhroma uses is the rendered page content described above, it is used solely for Zhroma's single purpose of colouring ticket rows by priority, and it is never transferred to anyone.

About this page

This policy page is a static document hosted on GitHub Pages. When you view it, GitHub — not Zhroma and not the publisher — records visitors' IP addresses for the security of its own hosting service, as described in GitHub's documentation. That is a consequence of visiting this website, and it is entirely separate from the Chrome extension, which makes no network requests and cannot cause any request to this page or anywhere else.

Children

Zhroma is a workplace tool for Zendesk support agents. It is not directed at children and collects no information from anyone.

Changes to this policy

If Zhroma's data practices ever change, this page will be updated before the change ships and the effective date above will be changed with it.
